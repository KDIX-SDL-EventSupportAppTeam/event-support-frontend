## メモ

設計書に内部矛盾が 2 件あり、司令塔の判断で次のとおり直した。いずれも設計の意図は変えていない。

1. **禁止語 `立会い` を外した。** 旧 `sampleQa.ts` に `立会い` は 0 件で、この禁止語は去年の文言を
   1 件も捕まえない一方、今年の正しい文言「スタッフの立会いはありません」（G-10）だけを誤検知していた。
   去年の運用の痕跡は `スタッフに見せ` / `スタッフにコイン` / `ガチャポンブース` が捕まえる。
   代わりに **T-4b「今年の運用が明記されていること」を積極的に確かめる it を追加**した（検査は強くなっている）。
2. **定数ファイル冒頭の注意書きから去年の日付の literal 表記を外した。** 「去年（2025-10-10/11）の内容を
   残さないこと」という注意書き自体が T-5 の grep に当たっていた。T-5 は「`src` に去年の日付が残っていない」
   ことを厳密に見る検査として残す価値があるため、grep を緩めず注意書きの表記を
   「去年（2025 年 10 月・2 日開催）」に変えた。
