# SDD: ビンゴカード段階解放方式（フロントエンド）

第4回プロトフェス（2026-10-16 金）向け、ビンゴカードを「中央4マス先行 → 外側12マス後出し解放」に作り替えるためのフロントエンド仕様書。

**API 契約の正本は `event-support-server/docs/.sdd/06-api/` である。** 本仕様書はそれを前提に、画面・状態・体験を定義する。数値やレスポンス形式が食い違った場合はサーバー側を正とする。

## 一言でいうと何が変わるか

参加者は最初、**中央2x2の4マスだけ**を持つ。うち1マスは「参加ありがとう」の**参加ボーナス**として達成済みで配られる。残る3マスは**自分が選んで訪問したブースが後出しで埋まる**。3件回り終えた瞬間に**外側12マスが開き**、推薦されたブースが現れる。

去年は「訪問6件に対して達成3マス」＝訪問の半分がカードに載っていなかった。後出し方式はこれを構造的に解消する。

## 絶対に守ること

1. **`state='LOCKED'` のマスの中身を表示しない。**サーバーは `booth: null` を返す。ローカルで推測して埋めない
2. **解放演出を楽観的に出さない。**解放はサーバー側の処理であり、フォールバックの結果次第で中身が変わる。チェックインレスポンスの `unlocked: true` を受け取ってから演出する（[02](02-bingo-card/unlock-animation.md)）
3. **「中央4マス完成 = コイン獲得」という表示をしない。**中央2x2 はラインを構成しないため、実際にコインは増えない。報酬は「12マスが開くこと」そのもの
4. **推薦を「推薦欄」のような外部 UI に切り出さない。**ビンゴカード自体に同化させる。これは企画の絶対条件である
