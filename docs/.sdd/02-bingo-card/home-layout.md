# ホーム画面の構成

## 3要素構成にする

ホーム画面は次の3つに絞る。

1. **ビンゴカード**
2. **推薦表示**（カードに同化させる。独立した「推薦欄」を作らない）
3. **チェックインボタン**

ガチャポン・スケジュール・アワード投票・ブース一覧は**フッターナビへ退避**する。
**チェックインを主 CTA に格上げする。**

## 理由

去年はチェックイン0件の参加者が50名いた。UX が原因と判断しており、本設計では「何をすればいいか」が一目で分かる構成にする。周遊促進の伸びしろは滞在時間ではなく**動機**の側にあり、動線の明快さが直接効く。

## 「推薦表示」の扱い（注意）

**推薦を独立した UI ブロックとして切り出してはならない。**これは企画の絶対条件である。

- 解放前: 推薦は存在しない。この領域には「あと N ブース回るとカードが広がります」のガイドを置く
- 解放後: 推薦は**カードの外側12マスそのもの**である。カードと別に推薦リストを並べない

既存の `CheckInRecommendView`（チェックイン後の推薦表示）の扱いは要検討（[Q-F1](../06-open-questions/open-questions.md)）。

## 既存ファイル

`src/features/home/pages/HomePage/HomePage.tsx` と `src/features/home/styles/legacy-home.scss` を対象にする。既存のチュートリアルモーダル（`HomeTutorialModal.tsx`）の文言も、**段階解放の説明に更新する必要がある**（「16マス埋めよう」ではなく「まず3ブース回ろう」）。
