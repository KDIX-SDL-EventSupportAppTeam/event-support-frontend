# 何を作るのか

## 参加者から見た流れ

1. **サインアップ直後** — カードを開くと 4x4 の枠がある。中央2x2 のうち1マスが既に埋まっており「ご参加ありがとうございます」のバッジが付いている。残り15マスのうち、中央3マスは空、外側12マスは「?」でロックされている
2. **画面には常に「あと3ブース回るとカードが広がります」** と出ている
3. **1件目のチェックイン** — 自分で選んだブースが、中央の空きマスに**後から入る**。「あと2ブース」に変わる
4. **2件目のチェックイン** — モーダルの**先頭で1件目のブースの評価**を聞かれる。星（3段階）を1タップ。続けてチェックイン成功が表示される
5. **3件目のチェックイン** — 中央が全部埋まる。**外側12マスが開く演出**が走り、推薦された12ブースが現れる
6. **以降** — マスをタップすると「なぜこのブースが選ばれたか」の理由が読める。ラインが揃うたびにガチャコインが1枚（最大4枚）

## なぜこうするのか（設計意図）

| 設計 | 意図 |
|---|---|
| 外側を最初ロックする | ゼロデータで16マスを決めるのは無理筋。3件の訪問と評価が溜まるまで待つ。**問題を解消せず先送りする** |
| 中央を後出しで埋める | 去年は訪問6件に対して達成3マス。**訪問の半分がカードに載っていなかった**。後出しなら解放前は全訪問が反映される |
| 参加ボーナス1マス | 実訪問コストを4件→3件に削減しつつ、「中央が埋まったら解放」という単純なルールを保つ。かつ有効な評価データを2件確保できる |
| 解放条件が3件 | 1件目の訪問は飲食に集中し**選好情報として使えない**。3件なら有効データ2件。DRSA は比較を要求するので最低2件の評価が要る |
| 解放を最大の報酬体験にする | 中央2x2 はラインを構成しないためコインは出ない。**「12マスが開く」こと自体が報酬**である。だから演出は簡素でよいが必ず入れる |

## 到達時間の想定

チェックイン間隔の中央値は 3.4分。3件で **10〜15分**。滞在30分未満の層（去年37%）でも届く設計になっている。

**ただし、中央3件を埋めきる前に帰る参加者は相当数出る。**外側が `LOCKED` のまま終わるのは**正常な状態**であり、エラー表示や催促を出してはならない。
