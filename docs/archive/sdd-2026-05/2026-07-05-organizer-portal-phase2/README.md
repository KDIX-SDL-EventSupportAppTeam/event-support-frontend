# SDD: 主催者ポータル Phase 2・運営画面改善（フロントエンド）

主催者ポータルを「ただのイベント作成画面」から「イベント一覧・詳細・スタッフ管理を備えた
ポータル」へ拡張し、あわせて運営画面の UX 改善を行う。
サーバー側 API 仕様は `event-support-server/.sdd/2026-07-05-organizer-portal-phase2/01-api.md` を正本とする。

## 背景（解消する UX 問題）

1. **ログインしても一覧が出ない** — ログイン成功後は直接 `/organizer/events/new` へ遷移し、
   過去に作ったイベントを見る手段がない
2. **スタッフ管理が作成時のみ** — 招待 UI の入口が作成完了画面に 1 回だけ。
   後から誰がいるか確認できず、ロール変更・削除もできない
3. **発行 URL を再確認できない** — URL カードは作成直後に一度だけ表示
4. 運営画面: viewer ガードの掛かっていない画面が残る／監査ログの閲覧画面がない／
   「どのイベントにいるか」が常時見えない、ほか（02 参照）

## 制約（確定事項）

- **DB 変更なし。** 開催ステータス（準備中 / 開催中 / 終了）は
  `date_start` / `date_end` と現在時刻からフロントで**導出**する。
  導出ロジックは既存 `EventInfoPanel` の `eventStatus()` を `shared/lib/` へ移して共用する
- feature 間の直接 import 禁止（既存原則）。organizer feature から admin feature の
  コードを import しない（共用が必要なものは `shared/` へ）
