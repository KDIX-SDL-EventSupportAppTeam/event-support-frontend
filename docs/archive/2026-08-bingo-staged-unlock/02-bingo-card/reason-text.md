# マスタップ時の理由文

## 仕様

マスをタップすると、**そのブースが選ばれた理由**を表示する。要点のみ提示し、タップで全文展開する。

`GET /bingo/card` の各セルに含まれる `reason` を表示する。

```json
"reason": { "summary": "…", "detail": "…" } | null
```

## 重要な制約

**★ 理由文の生成ロジックは未決定である**（[サーバー Q-3](../../../../event-support-server/docs/.sdd/09-open-questions/open-questions.md)）。

→ **表示コンポーネントとデータ受け渡し口だけ作る。**
→ `reason === null` の場合は理由セクションを出さない（プレースホルダも出さない）。当面はこれが常態である
→ 文言をフロント側で生成しない。**サーバーから来た文字列をそのまま出す**

理由文はこの研究の中核（DRSA を「説明可能な選択フィルタ」として使う）に直結する部分であり、フロント側で仮の文言を作ると、後から本物に差し替える際に「どちらが本物か」が分からなくなる。

## 手動評価の導線

**マスのタップから、そのブースの評価を入力できる導線をここに置く。**
最後に訪問した1件はチェックインモーダル経由では取り逃すため、この導線が唯一の回収経路になる（`context: 'MANUAL'`。[03-checkin-flow](../03-checkin-flow/rating-modal.md)）。

- 対象は `ACHIEVED` かつ未評価のマスのみ
- カード外訪問（カードに載っていないブース）の未評価分は、**チェックイン履歴側から**同様に評価できるようにする
