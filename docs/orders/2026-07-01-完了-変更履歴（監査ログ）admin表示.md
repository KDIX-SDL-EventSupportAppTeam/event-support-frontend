## 背景

運営画面（admin）で「どのアカウントがどんな操作をしたか」を確認したい。
サーバーには取得 API（`GET /admin/events/:event_id/audit-logs`）が既にあるが、
フロントに表示画面が無かった。あわせてサーバー側でレスポンスに `actor_email` を追加した。

## 目的

admin に「変更履歴」ページを追加し、**日時 / 操作者（表示名＋メアド）/ 操作 / 対象**を
シンプルなテーブルで一覧表示する。manager / viewer どちらのロールでも閲覧可能。

## 受け入れ条件

- サイドバー「変更履歴」→ `/admin/audit-logs` で一覧が表示される。
- 各行に日時・操作者の表示名・メアド・権限バッジ・操作ラベル（色分け）・対象が出る。
- ログが空・取得失敗・読み込み中の各状態を表示する。
- 51 件以上でページネーションが機能する（`PAGE_SIZE=50`）。
- `npx tsc --noEmit` がクリーン（本 feature 起因のエラーなし）。

## 実装メモ

- action ラベルは target/verb を分解して合成するため、サーバーが既知の
  target・verb の組み合わせで新 action を足しても自動で日本語化される
  （未知語はコードそのまま + `secondary` バッジ）。
- ローカル確認時、追加した運営者で admin に入れず 401 になる場合は
  ログイン先イベントの不一致が原因。frontend `.env` の `VITE_DEV_EVENT_ID` を
  対象イベントに合わせて **Vite 再起動**（コード変更不要）。
