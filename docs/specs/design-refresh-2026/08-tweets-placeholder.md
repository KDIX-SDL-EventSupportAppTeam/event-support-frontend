# つぶやき導線（ボタンのみ）

作業ブランチ: `feat/design/tweets-button`

**前提**：[03](03-bottom-navigation.md) が終わっていること。

## 範囲 ★重要

**ボタンを 1 つ置くだけ。** 画面も機能も作らない。

```
  やる                        やらない
  ────────                    ──────────
  ホームにボタンを1つ置く     つぶやきの投稿・一覧画面
  押しても何も起きない        API 通信・データ設計
  （または準備中を出す）      ルートの追加
```

つぶやき機能はこのリポジトリに**存在しない**（feature もルートも無い）。
先に UI の置き場所だけ確保しておくのがこの PR の目的である。

## 素材は使わない

**つぶやき関連の素材は未受領である。**（鉛筆アイコン・ハート・吹き出しなど）

**HTML と CSS だけで組む。** 画像を待たない。
アイコンが要る場合は既に導入済みの `bootstrap-icons` を使う（例 `bi-chat-dots`）。
`src/main.tsx` で読み込み済みなので追加インストールは不要。

素材が必要になった時点で、**何が必要かを一覧にして報告すること。**
勝手に既存素材で代用しない。

## 置き場所

`HomePage` の副導線（アプリ説明 / Q&A / アプリフィードバックの段）に並べる。
[03](03-bottom-navigation.md) でボタングリッドを消した後の配置に合わせること。

**ボトムナビには載せない。** ナビは 5 項目で確定している。

## 押したときの挙動

**準備中であることを伝える。** 押しても無反応にしない。

既存のガチャポン準備中表示に倣うのが最も安全である。
`src/features/gachapon/` の準備中の出し方を読み、同じ作法に揃えること。
**新しいパターンを発明しない。**

`disabled` にする場合は、**なぜ押せないかが分かる表示を添える。**
理由の無い `disabled` は置かない。

## 完了の条件

- ホームにつぶやきボタンがあり、2026 年版の配色に馴染んでいる
- 押すと準備中であることが伝わる
- 画像素材を 1 つも新規に使っていない
- `npm run test` と `npm run build` が通る
