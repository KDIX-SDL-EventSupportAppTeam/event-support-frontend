# ユビキタス言語定義（フロントエンド）

このリポジトリで使用する用語の定義。
**コード・ドキュメント・会話すべてでこの語彙を統一して使う。**

新しい用語を導入する／既存の語を変更する場合は本ファイルを更新し、関連する AI ドキュメント・ADR を見直すこと。

---

## アクター

| 日本語 | コード上の名前 | 定義 |
|---|---|---|
| 参加者 | `user` / `participant` | イベントに参加しブースを回る人。アプリにログインして使う主役 |
| 出展者 | `exhibitor` | ブースを出す人。Googleフォームでブース情報を登録する |
| 運営 | `admin` / `organizer` | イベントを管理する人。ダッシュボードで状況を把握する |

---

## イベント

| 日本語 | コード上の名前 | 定義 |
|---|---|---|
| イベント | `event` | アプリが対象とする展示会・カンファレンス等の全体 |
| イベントID | `event_id` | イベントを一意に識別する UUID。ログイン後 JWT に含まれる |

---

## ブース

| 日本語 | コード上の名前 | 定義 |
|---|---|---|
| ブース | `booth` | 出展者が設置する展示スペース。チェックインの対象単位 |
| ブースID | `booth_id` | ブースを一意に識別する UUID |
| 手動コード | `manual_code` | QR が使えない場合に代わりに入力する6桁の英数字コード |
| QRコード | `qr_code` | ブースに設置する。スキャンするとチェックイン画面に遷移する |
| カテゴリ | `category` | 運営が定義するブースの分類。ブース一覧のフィルタに使う |
| タグ | `tag` | ブースに付与するフリーワードの属性 |
| ブース特性ラベル | `label` | チェックイン数・滞在時間・訪問者属性から算出する動的なバッジ |

### ブース特性ラベルの種類

| ラベル | 定義 |
|---|---|
| 🔥 急上昇中 | 直近のチェックイン数が急増している |
| 💎 じっくり系 | 推定滞在時間が長い |
| 🎲 意外な人気 | 自分と異なる属性の人が多く訪問している |
| 👥 幅広い支持 | 訪問者の属性エントロピーが高い |

---

## チェックイン

| 日本語 | コード上の名前 | 定義 |
|---|---|---|
| チェックイン | `check_in` | 参加者がブースを訪問したことをアプリに記録する行為 |
| チェックインID | `checkin_id` | チェックインレコードを一意に識別する UUID。評価・推薦に使う |
| チェックイン方法 | `checkin_method` | チェックインの手段。`qr`（QRスキャン）または `manual`（手動コード入力）|
| チェックイン日時 | `checked_in_at` | 参加者がQRをスキャンした瞬間の日時（クライアント側で記録） |
| 同期日時 | `synced_at` | オフラインキューからサーバーへの送信が完了した日時 |
| 二重チェックイン | — | 同一参加者が同一ブースに2回チェックインしようとすること。`CONFLICT` エラーで弾く |

---

## 評価

| 日本語 | コード上の名前 | 定義 |
|---|---|---|
| 評価 | `rating` | チェックイン直後に参加者がブースにつける1〜5段階の満足度 |
| 評価ID | `rating_id` | 評価レコードを一意に識別する UUID |
| スキップ | — | 評価しないまま次へ進む選択。エンドポイントを叩かずに推薦へ進む |

---

## 推薦

| 日本語 | コード上の名前 | 定義 |
|---|---|---|
| 推薦 | `recommendation` | チェックイン・評価後にシステムが提示する次のブース候補3択 |
| 推薦ID | `recommendation_id` | 推薦レコードを一意に識別する UUID。選択送信時に使う |
| 推薦枠 | `recommend` | 参加者の属性・行動履歴に基づくパーソナライズ推薦 |
| 準推薦枠 | `semi_recommend` | 属性はやや外れるが関連性がある推薦 |
| ディスカバリー枠 | `discovery` | 属性スコアは低いが他参加者の評価が高い「意外なブース」 |
| 推薦理由 | `reason` | 推薦枠の種別。UI上のバッジ表示に使う |
| 選択 | `select` | 参加者が3択の中から次のブースを1つ選ぶ行為 |

## 認証・ユーザー

| 日本語 | コード上の名前 | 定義 |
|---|---|---|
| ユーザー | `user` | 参加者のアカウント。イベントごとに作成される |
| ユーザーID | `user_id` | ユーザーを一意に識別する UUID |
| 表示名 | `display_name` | アプリ内で表示される参加者の名前 |
| メールアドレス | `email` | ログインに使うメールアドレス |
| パスワード | `password` | ログインに使う8文字以上の文字列 |
| JWTトークン | `token` | ログイン後に発行される認証トークン。API リクエスト時に Bearer で付与する |

## アンケート

| 日本語 | コード上の名前 | 定義 |
|---|---|---|
| アンケート | `survey` | 初回ログイン時に参加者が回答する設問群 |
| 固定設問 | `fixed_questions` | 全イベント共通の設問。年齢層・職業・業種の3項目 |
| カスタム設問 | `custom_questions` | 運営がイベントごとに設定する追加設問 |
| アンケート回答 | `survey_answer` | 参加者が回答した内容 |
| 年齢層 | `age_range` | 固定設問の1つ。10代〜50代以上の5択 |
| 職業 | `occupation` | 固定設問の1つ。学生・会社員・経営者・その他の4択 |
| 業種 | `industry` | 固定設問の1つ。IT・製造・金融・医療・その他の5択 |

---

## 運営・ダッシュボード

| 日本語 | コード上の名前 | 定義 |
|---|---|---|
| ダッシュボード | `dashboard` | 運営がリアルタイムで参加者の動向を把握する管理画面 |
| チェックイン総数 | `total_checkins` | イベント全体のチェックイン件数 |
| 参加者数 | `total_participants` | イベントに登録した参加者の人数 |
| 属性別分布 | `visitor_breakdown` | ブースの訪問者を年齢層・職業等の属性で集計したデータ |
| チェックインタイムライン | `checkin_timeline` | 時間帯ごとのチェックイン件数の推移 |

## オフライン対応

| 日本語 | コード上の名前 | 定義 |
|---|---|---|
| オフラインキュー | `offline queue` | 通信失敗時にチェックイン情報を一時保存する仕組み |
| 自動リトライ | — | WiFi 回復後にキューの送信を自動で再試行する動作 |
| PWA | — | Progressive Web App。オフライン対応・ホーム画面追加を可能にする |
| Service Worker | — | バックグラウンドで動作しオフラインキューを管理するブラウザの仕組み |

## API 規約

| 日本語 | コード上の名前 | 定義 |
|---|---|---|
| 成功レスポンス | `{ success: true, data: {...} }` | API が正常に処理した場合のレスポンス形式 |
| 失敗レスポンス | `{ success: false, error: { code, message } }` | API がエラーを返す場合のレスポンス形式 |
| 未認証 | `UNAUTHORIZED` | トークンがない・無効な場合のエラーコード |
| 未発見 | `NOT_FOUND` | 指定したリソースが存在しない場合のエラーコード |
| 競合 | `CONFLICT` | 二重チェックイン・重複登録の場合のエラーコード |
| バリデーションエラー | `VALIDATION_ERROR` | リクエストの形式・値が不正な場合のエラーコード |
